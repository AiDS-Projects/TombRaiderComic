# PRD — 第一集分镜拆解：产出 shot_prompts 索引

> 所属需求：第一集试片：龙三角的呼唤

## 用户故事
As 视频导演，I want 将第一卷第一章「龙三角的呼唤」拆解为结构化的分镜 Prompt 索引（shot_prompts），So that 后续可按索引逐镜完成「生图→配音→合成」，并形成第一集可复用的制作流水线。

## 功能需求
产出「龙三角的呼唤」第一集试片的分镜索引文件 shot_prompts.json，存于 works/dragon-triangle-ep1/ 目录下。每个镜头条目必须包含以下字段：shot_id（序号）、character（出场角色）、scene（场景描述）、camera_motion（镜头运动，如推/拉/摇/移/固定）、duration（时长，单位秒）、keyframe_prompt（关键帧 Prompt，含角色+场景+运动三要素）。分镜需遵循导演规范：剧情正式片段 720p、单镜最长 15 秒、相邻镜头默认硬切不写装饰性转场。索引按情节顺序排列，并在文件头部写入 Mode=Drama 与剧情定位说明，便于后续工序直接消费。

## 验收标准
1. shot_prompts 索引产出镜头数 ≥ 8 个，覆盖本章节核心情节（含开场/冲突/悬念收尾）。
2. 每个镜头条目字段完整率 = 100%（shot_id/character/scene/camera_motion/duration/keyframe_prompt 六字段均非空）。
3. 每个镜头 duration 取值范围 5–15 秒，全片累计总时长 60–120 秒。
4. keyframe_prompt 100% 同时包含角色、场景、镜头运动三类信息，无缺失项。
5. 索引文件为合法 JSON，可被脚本一次性解析无报错。

## 边界条件（不做的事）
不做：生成图片/关键帧、视频合成、配音、配乐、网页或 Next.js 前端。不做：批量生成整集全部镜头的成片，本工单仅产出分镜索引。不包含：video_brief 的重写（Mode 已在上一工单确定为 Drama）。超出范围：第 2 章及以后章节的分镜。

## 资产需求线索
暂无。本工单仅产出文本索引，不触发任何生图/生视频。若后续进入生图工序，需补充：劳拉角色设定图（三视图）、龙三角海域场景概念图（风暴/海面/沉船）、关键道具（船/罗盘/遗迹）参考图。

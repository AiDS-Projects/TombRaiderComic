# PRD — 第一集视频简报：定 Mode 与剧情定位

> 所属需求：第一集试片：龙三角的呼唤

## 用户故事
As a 导演/制片，我想要为「第一集试片：龙三角的呼唤」产出一份视频简报（video_brief），明确本片的 Mode 与剧情定位，So that 后续分镜拆分、关键帧生图、配音与合成有统一且可复用的创作方向依据。

## 功能需求
功能点 1：确定 Mode——本项目为写实电影感 AI 漫剧，选用 cinematic-drama（剧情影像），不用 animated-explainer 或 storytime-animation。[假设] 用户未明确指定，依据背景「倾向 Drama」推断；功能点 2：剧情定位——基于第一卷第一章「龙三角的呼唤」确定剧情梗概、核心冲突与主角劳拉的人物动机；功能点 3：目标时长与受众——明确本片目标时长与目标受众（如 18-35 岁动作冒险/漫剧受众）；功能点 4：风格方向——确定写实电影感画面风格、色调基调与镜头语言基调，作为后续生图与分镜的锚点；功能点 5：产出物落盘——将 video_brief 保存至当前仓库 works/ 目录下以 slug 命名的独立子目录，便于后续工作包引用。

## 验收标准
- [ ] video_brief 文档产出，包含 Mode 字段且值为 cinematic-drama（非 Explainer/Storytime），可被脚本字段级读取校验
- [ ] 剧情定位段落包含明确的剧情梗概（≥50 字）与核心冲突描述，不出现「剧情不错」「定位清晰」等模糊表述
- [ ] 目标时长以具体数值写出（如 60-90 秒），目标受众明确到年龄段/兴趣标签（≥1 个受众标签）
- [ ] 风格方向至少列出画面风格、主色调、镜头语言基调 3 个维度的具体描述
- [ ] video_brief 保存于 works/<slug>/ 目录，slug 为英文小写连字符格式（如 dragon-triangle-ep1），不含中文与空格
- [ ] 交付物为 1 份 video_brief，不含分镜 Prompt 列表（分镜为下一工作包）

## 边界条件（不做的事）
- 不包含：分镜（shot_prompts）拆分与分镜 Prompt 索引（属下一工作包）
- 不包含：调用 gen_video / LightAI 等后端实际生成视频或关键帧
- 不包含：配音、BGM、音效与最终合成
- 不包含：网页 / Next.js / 前端页面开发
- 不包含：完整生成整集全部镜头，本次只到视频简报为止
- 暂不支持：MV、真人出镜口播等非既定 Mode 的创作类型

## 资产需求线索
暂无。本次为视频简报（Mode 与剧情定位）产出，不涉及图标、插画、背景图、音效、BGM、骨骼动画或粒子特效等实体资产；后续分镜/生图阶段需补充角色设定图（劳拉）、龙三角海域场景参考图等线索。

# 视觉规范 — 搭建项目脚手架并建立章节数据模型与 mock 数据源

> 所属需求：TombRaiderComic 网页 MVP：核心页面与主流程

## 整体风格
整体采用现代扁平化设计，默认深色主题营造探险与神秘氛围，以考古金色（#E0A93E）为主色、海洋青（#14B8A6）为点缀，呼应「龙三角」的海洋与宝藏意象。标题使用衬线 display 字体增强电影感与叙事性，正文使用无衬线保证可读性。所有卡片、按钮、弹窗统一使用 4-16px 圆角与分层阴影，交互状态（hover/loading/empty）均有明确的视觉反馈，保持克制不堆砌装饰。

## 组件视觉规范

## AppShell / Header
- 背景：`surface` 半透明 + `backdrop-filter: blur(12px)`，底部 1px `border` 分隔
- 高度 64px；Logo 使用 `display` 字体、`bold`、`heading` 字号，主色 `primary`
- 面包屑：`sm` 字号，当前层级 `text`，父级 `text_muted`，分隔符 `/`
- sticky 置顶，`z-index: 100`

## Footer
- 背景 `bg`，上边框 1px `border`，文字 `xs` / `text_muted`，居中对齐
- 高度自适应，内边距 `md`

## ChapterCard（章节卡片）
- 背景 `surface`，圆角 `lg`，阴影 `md`，hover 时阴影升级为 `lg` + 上浮 4px（transition 200ms）
- 封面缩略图：16:9，顶部圆角 `lg`，`object-fit: cover`，加载前显示 `surface_alt` 占位
- 标题 `lg` / `semibold`，卷章编号 `xs` / `text_muted`（胶囊标签，`primary` 10% 透明背景 + `primary` 文字）
- 简介 `sm` / `text_muted`，最多 2 行省略
- hover 状态：边框变为 `primary`，封面轻微放大（scale 1.03）

## ChapterHeader（章节页头）
- 背景 `bg`，内边距 `xl`，标题 `display` / `bold`（display 字体），副标题/卷次 `base` / `text_muted`
- 分镜总数徽标：`sm` 胶囊，`accent` 10% 透明背景 + `accent` 文字

## StoryboardGrid（分镜网格）
- Grid 布局：1 列（sm）/ 2 列（md）/ 3 列（lg），间距 `md`
- 容器内边距 `lg`

## StoryboardCard（分镜卡片）
- 背景 `surface`，圆角 `md`，阴影 `sm`，hover 阴影 `md`
- 剧照缩略图 4:3，序号徽标左上角（`sm`，`overlay` 背景 + 白色文字）
- 对白/旁白摘要 `sm`，底部内边距 `md`，1 行省略

## StillViewer（全屏查看器）
- 背景 `overlay`（模糊暗化），居中弹层，圆角 `xl`，阴影 `lg`
- Stage 大图：自适应 max-width 90vw / max-height 70vh，`object-fit: contain`
- Caption：底部半透明 `surface` 条，`base` / `text`，内边距 `md`
- Controls：圆角 `full` 按钮，`surface` 背景，hover `primary`；页码指示 `sm` / `text_muted`
- 关闭按钮右上角，ESC 可关闭

## Skeleton（骨架屏）
- 背景 `surface_alt`，脉冲动画（opacity 1 → 0.5，1.5s 循环）
- 圆角 `md`，尺寸与对应真实卡片一致

## EmptyState（空状态）
- 居中布局，插画 400x300，标题 `lg` / `semibold`，说明 `sm` / `text_muted`
- 重试按钮：`primary` 背景，白色文字，圆角 `md`，hover `primary_hover`

## 主题切换
- 深色为默认（漫画阅读场景），支持手动切换浅色；所有 token 通过 CSS 变量注入
